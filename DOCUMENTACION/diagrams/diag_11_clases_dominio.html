Diagrama de Clases del Dominio (Domain Entities & Value Objects)

User
+ id: string (UUID)
+ email: string
+ passwordHash: string
+ fullName: string
+ role: UserRole
+ isActive: boolean
+ validatePassword(pwd): boolean
+ hasPermission(action): boolean
Project
+ id: string (UUID)
+ name: string
+ description: string
+ status: ProjectStatus
+ budgetUsd: number
+ nextRequirementNumber: int
+ getNextRequirementCode(): string
+ isBudgetExceeded(spent): boolean
Requirement
+ id: string (UUID)
+ projectId: string
+ code: string (REQ-001)
+ title: string
+ description: string
+ acceptanceCriteria: string
+ version: int
+ nextCaseNumber: int
+ createVersionSnapshot(): ReqVersion
+ getNextCaseCode(): string
TestCase
+ id: string (UUID)
+ requirementId: string
+ generationId: string
+ code: string (CP-001)
+ type: ISTQBTechnique
+ title: string
+ preconditions: string[] (JSON)
+ steps: string[] (JSON)
+ testData: string
+ expectedResult: string
+ version: int (optimistic)
+ status: TestCaseStatus
+ approve(reviewerId, just): void
+ reject(reviewerId, comment): void
TestCaseReview
+ id: string (UUID)
+ testCaseId: string
+ reviewerId: string
+ decision: ReviewDecision
+ comments: string
+ justification: string
+ previousContent: JSON
+ newContent: JSON
+ getAuditSnapshot(): SnapshotDiff
AiGeneration
+ id: string (UUID)
+ requirementId: string
+ provider: string (gemini/openai)
+ model: string
+ inputTokens: int
+ outputTokens: int
+ estimatedCost: float
+ responseTimeMs: int
+ inputHash: string
+ status: GenStatus
+ calculateCost(pricing): float
